# Démo exercices interactifs

Cette page montre comment utiliser les composants `<Quiz />` et `<FillInBlank />` dans les pages MDX.

## QCM — Choix unique

<Quiz
  id="demo-qcm-1"
  title="Les types de base"
  questions={[
    {
      question: "Quel type utilise-t-on pour stocker un nombre entier ?",
      options: ["reel", "entier", "booleen", "string"],
      correctAnswers: [1],
      explanation: "`entier` est le type pour les nombres sans virgule. `reel` est pour les nombres à virgule.",
    },
    {
      question: "Comment déclare-t-on une variable entière nommée `age` ?",
      options: [
        "declarer age : entier;",
        "age <- entier;",
        "entier age;",
        "var age = entier;",
      ],
      correctAnswers: [0],
      explanation: "La syntaxe correcte est `declarer nom : type;`. L'opérateur `<-` sert à affecter une valeur, pas à déclarer.",
    },
  ]}
/>

## Texte à trous

<FillInBlank
  id="demo-fillblank-1"
  title="Déclarer et affecter"
  blanks={[
    {
      before: "Pour déclarer une variable entière nommée ",
      accepted: ["compteur"],
      after: ", on écrit : ",
    },
    {
      before: "declarer ",
      accepted: ["compteur"],
      after: " : ",
    },
    {
      before: "entier; Pour lui donner la valeur 5, on utilise l'opérateur ",
      accepted: ["<-"],
      after: " : compteur ",
    },
    {
      before: " ",
      accepted: ["<-"],
      after: " 5;",
    },
  ]}
  hint="La syntaxe de déclaration est `declarer nom : type;` et l'affectation utilise `<-`."
/>
