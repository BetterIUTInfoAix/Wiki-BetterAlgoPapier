# Installation

## VSCode

Panneau extensions (`Ctrl+Maj+X`), chercher **Better Algo Papier**, **Installer**. Ou :

```
ext install betteriutinfoaix.better-algo-papier
```

Marketplace : [betteral­gopapier sur VS Marketplace](https://marketplace.visualstudio.com/items?itemName=betteriutinfoaix.better-algo-papier).

## VSCodium

Panneau extensions, chercher **Better Algo Papier**, ou via [Open VSX](https://open-vsx.org/extension/betteriutinfoaix/better-algo-papier).

## Depuis un .vsix

1. Télécharger le `.vsix` de la [dernière Release](https://github.com/BetterIUTInfoAix/BetterAlgoPapier/releases/latest).
2. Panneau extensions → `...` → **Installer à partir d’un VSIX…**.

```bash
code --install-extension better-algo-papier-X.Y.Z.vsix
codium --install-extension better-algo-papier-X.Y.Z.vsix
```
